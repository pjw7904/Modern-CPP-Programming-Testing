## Claude

Here are the main approaches, with tradeoffs:

**Option 1: Stop Hook (most automatic)**
Configure a `Stop` hook in `.claude/settings.json` that fires when each session ends. The hook runs a script that reads Claude Code's session JSONL file from `~/.claude/projects/` and converts it to a dated markdown file in your repo. Zero effort after setup.

**Option 2: Custom `/save-session` command**
A shell alias or script you invoke manually at the end of a session. Less automatic, but you control exactly when/what gets saved and can add a session title.

**Option 3: Pre-commit hook**
Every time you commit to the repo, a git hook checks for unsaved session data and appends it. Useful if you already commit after each study session.

**My recommendation: Option 1** — it's the closest to truly automatic. The main tradeoff is that the Stop hook fires after *every* Claude turn, not just at "session end," so the script needs to either overwrite or append to a daily file. Claude Code stores sessions as JSONL in `~/.claude/projects/<hash>/`, which includes full conversation turns.

The rough setup would be:
1. A conversion script (`scripts/save_session.sh`) that finds the latest session file and renders it as markdown
2. A `Stop` hook entry in `.claude/settings.json` pointing to that script
3. A `sessions/` directory in this repo for the output

Want me to implement Option 1? I'd also check your `~/.claude/projects/` structure first to confirm the session file format before writing the conversion script.
